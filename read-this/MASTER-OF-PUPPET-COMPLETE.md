## ⚗️ The Alchemical Loop

**Runs every 30 seconds (configurable):**

### PHASE 1: OBSERVATION 👁️ (10 seconds)
Second-Me watches all servants:
```
"CodeScribe completed 5 quests with 92% success"
"Analyst-02 failed on complex data analysis"
"Team success rate: 88% this hour"
```

### PHASE 2: REFLECTION 🧠 (10 seconds)
Second-Me analyzes patterns:
```
"Why do some servants fail?"
"What patterns led to success?"
"Which servants improved? By how much?"
"Is the system improving overall?"
```

### PHASE 3: TRANSMUTATION ⚗️ (10 seconds)
Second-Me applies changes:

| Transmutation | Effect |
|---|---|
| **Pact Modification** | Refines system prompt for struggling servant |
| **Tier Advancement** | Promotes high-performers to next tier |
| **Specialization Add** | Grants new skills based on patterns |
| **Artifact Restriction** | Removes misused tools |
| **Temperature Adjust** | Tunes creativity vs consistency |
| **Invocation** | Suggests creation of new servant |

**Example:**
```
📊 Observed: Analyst-02 success rate = 62% (below target)
💭 Reflection: Temperature too high, making inconsistent decisions
⚗️ Transmutation: Reduced temperature 0.9 → 0.7
✅ Expected Impact: More consistent outputs
```

## 🚀 How to Use

### Initialization
```tsx
const puppet = useMasterOfPuppet();
puppet.start();
```

### Awaken a Servant
```tsx
const servant = puppet.awokenServant({
  systemPrompt: "You are an expert...",
  allowedArtifacts: ["Claude API"],
  model: "claude-opus-4.5",
  specializations: ["TypeScript", "React"],
  temperature: 0.7,
  maxTokens: 4000,
}, "CodeScribe-01", "📚");
```

### Give Them a Quest
```tsx
puppet.completeQuest(
  servant.id,
  "Write a React hook",
  true,                    // successful
  95,                      // performance score
  2500,                    // tokens used
  5000,                    // execution time (ms)
  "Excellent implementation"
);
```

### Form a Team
```tsx
puppet.formTeam("Content Squadron", [
  imageWeaver.id,
  scriptMaster.id,
  soundScribe.id,
]);
```

### Watch Second-Me Evolve Them
The alchemical loop runs automatically:
- Observes performances
- Reflects on patterns
- Transmutes improvements
- Chronicles evolution
